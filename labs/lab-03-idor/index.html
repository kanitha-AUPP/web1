WebPentest101 / Lab 03 VULNERABLE MODE

IDOR Order Viewer

Difficulty: Easy · Goal: read another customer's order by changing the ID.

You are logged in as you, and your own order is number 1. The page loads an order by its ID number. In the vulnerable version it never checks who owns the order.

My order
Need a hint?

Your order is number 1. Other customers have orders too. What happens if you ask for order number 2 or 3?

Show the solution

Change the Order ID to 2 (or 3) and click View order. You can see another customer's order, even though it is not yours. That is an Insecure Direct Object Reference (IDOR).

Switch to the fixed version and try ID 2 again. Now the server checks the owner and refuses.

How this lab is built

Open app.js to see how it works. The "database" or "server" is just a small JavaScript object, and the vulnerable and fixed versions are two separate functions so you can compare them.
