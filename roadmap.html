Section 04

Roadmap & Resources

A four-stage plan for learning web security, and the best free places to keep going after WebPentest101.

The learning roadmap

Work through the stages in order. You do not need to finish everything in a stage before you start the next, but the earlier stages make the later ones much easier.

  1. Stage 1

    Fundamentals

    Understand how the web works before you try to break it.

    • Basic networking (IP addresses, ports, DNS)
    • Linux fundamentals and the command line
    • How HTTP and HTTPS work
    • HTML, CSS and JavaScript
    • How websites and servers fit together
  2. Stage 2

    Web security fundamentals

    Learn the common problems and the main tools.

    • The OWASP Top 10
    • Common web vulnerabilities (our Learning section)
    • Burp Suite basics
    • Reading HTTP requests and responses
  3. Stage 3

    Hands-on practice

    Apply what you know in safe, legal environments.

    • Beginner web security labs
    • Identifying vulnerabilities yourself
    • Understanding a testing workflow
    • Writing simple vulnerability reports
  4. Stage 4

    Advanced learning

    Go deeper with full platforms and courses (see the resources below).

    • Structured web-security courses
    • Guided and then unguided machines
    • Capture-the-flag (CTF) events
    • Specialising in an area you enjoy

Resources

Free (or free to start) platforms we recommend. Each card explains what beginners can learn there.

PortSwigger Web Security Academy

What it is
Free lessons and hands-on labs from the team that makes Burp Suite.
What beginners can learn
Each vulnerability step by step, with a lab to try straight away in the browser.
portswigger.net/web-security →

TryHackMe

What it is
Guided "rooms" with a practice machine that runs in your browser.
What beginners can learn
The basics of hacking and defence with lots of hand-holding, so no lab setup is needed.
tryhackme.com →

Hack The Box

What it is
Practice machines and challenges, from beginner (Starting Point) to advanced.
What beginners can learn
How to find and use vulnerabilities on realistic targets once you know the basics.
hackthebox.com →

OWASP

What it is
A non-profit that publishes the Top 10 and the Web Security Testing Guide.
What beginners can learn
What each risk is and how testers check for it. A reference to return to often.
owasp.org →

OWASP Juice Shop

What it is
A free, deliberately vulnerable web shop that you run on your own computer.
What beginners can learn
Finding many different bugs in one realistic app, with built-in challenges and hints.
owasp.org/www-project-juice-shop →

PayloadsAllTheThings

What it is
An open-source collection of testing techniques for many vulnerabilities (MIT License).
What beginners can learn
Real examples for each vulnerability. It is the main source for our Cheatsheet.
github.com/swisskyrepo/PayloadsAllTheThings →
