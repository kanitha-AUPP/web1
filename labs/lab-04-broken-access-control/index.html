WebPentest101 / Lab 04 VULNERABLE MODE

Broken Access Control

Difficulty: Intermediate · Goal: open the admin page as a normal user.

You are logged in as a normal user. The menu only shows the Dashboard, but the admin page still exists at its own address. In the vulnerable version, the admin page does not check your role.

Go to page

You are: normal user (role: user)

Need a hint?

A link being hidden from the menu does not mean the page is protected. Try visiting the page named admin directly.

Show the solution

Type admin and click Visit page (or use the admin button). The admin panel opens, even though you are only a normal user.

Switch to the fixed version and try again. Now the page checks your role on the server and blocks you.

How this lab is built

Open app.js to see how it works. The "database" or "server" is just a small JavaScript object, and the vulnerable and fixed versions are two separate functions so you can compare them.
