WebPentest101 / Lab 05 VULNERABLE MODE

Command Injection Ping Tool

Difficulty: Intermediate · Goal: run an extra command through the ping tool.

Practice lab - safe to run. Everything here is simulated inside your browser. There is no real server or database, and nothing is sent over the internet. Only practise these techniques here or on sites made for practice.

This "network tool" pings an address you type. In the vulnerable version it builds a system command by joining your input into a string, so extra commands can be added.

Ping tool

Command that will run:

ping -c 4 8.8.8.8
Need a hint?

In a shell, a semicolon ; separates two commands. What if your input contained a semicolon and a second command after it?

Show the solution

Put this in the address box and run it:

8.8.8.8; cat /etc/passwd

The command becomes ping -c 4 8.8.8.8; cat /etc/passwd. The ping runs, then the second command prints a system file. (Here it is a pretend file - on a real server this would be the real one.)

Switch to the fixed version and try the same input. It checks that the address is a valid host and refuses anything else.

How this lab is built

Open app.js to see how it works. The "database" or "server" is just a small JavaScript object, and the vulnerable and fixed versions are two separate functions so you can compare them.
