Need a hint?

The page writes You searched for: <your text> into the results area. If your text is treated as HTML, an image tag that fails to load can run code through its onerror handler.

Show the solution

Type this into the search box and press Search:

<img src=x onerror=alert('XSS')>

The image src=x cannot load, so the browser runs the onerror code and a pop-up appears. On a real site, that code could steal cookies or change the page.

Switch to the fixed version and try again. The fixed page shows your text as plain words instead of running it.

How this lab is built

Open app.js to see how it works. The "database" or "server" is just a small JavaScript object, and the vulnerable and fixed versions are two separate functions so you can compare them.
