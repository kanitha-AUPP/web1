This login form builds an SQL query by joining your input into a text string. Because of that, the right input can change the query and log you in without a real password.

Need a hint?

In SQL, a single quote ' ends a piece of text, and -- starts a comment (the rest of the line is ignored). What if the username itself contained a quote and an always-true condition?

Show the solution

Put this in the username box and type anything as the password:

' OR '1'='1' --

The query becomes ... WHERE username='' OR '1'='1' --' AND password='...'. '1'='1' is always true and -- comments out the password check, so the database returns the first user (admin).

Now switch to the fixed version and try the same input. The fixed login does not build a query from text at all, so the injection does nothing.
