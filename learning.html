Section 01

Learning

Ten lessons on the web vulnerabilities you will meet most often. Each lesson explains what the problem is, how it works, how testers find it and how developers prevent it.

Before you start

Every lesson follows the same structure, so you always know where to find things:

  1. What is this vulnerability?
  2. How does it work?
  3. Why is it dangerous?
  4. A simple technical example
  5. How to identify it during authorised testing
  6. Common developer mistakes
  7. How to prevent it
  8. Related learning resources

The 10 lessons

We suggest following them in order. Lessons 1-2 are about injecting code, 3-5 are about who is allowed to do what, and 6-10 are about the server itself.
