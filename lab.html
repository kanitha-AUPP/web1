Section 03

Lab

Practice materials you can download and run on your own computer to see each vulnerability safely for yourself.

Practice labs

Each lab is a small website with one built-in weakness. Download it, unzip it, and open index.html in your browser. There is nothing to install, and each lab has a Vulnerable / Fixed switch so you can see the problem and the fix.

Lab 01 Beginner

SQL Injection login

Goal: log in as the admin without knowing the password by changing the SQL query.

What you will learn

How untrusted input can change a database query, and why parameterised queries fix it.

Download lab (ZIP)
Lab 02 Easy

Reflected XSS search

Goal: make a search box run your own JavaScript.

What you will learn

Why output must be encoded, and how textContent stops a script from running.

Download lab (ZIP)
Lab 03 Easy

IDOR order viewer

Goal: change an ID to view another customer's order.

What you will learn

Why the server must check who owns a record, not just that someone is logged in.

Download lab (ZIP)
Lab 04 Intermediate

Broken access control

Goal: open an admin page as a normal user.

What you will learn

Why hiding a link is not protection, and why roles must be checked on the server.

Download lab (ZIP)
Lab 05 Intermediate

Command injection ping tool

Goal: run an extra command through a "ping" tool.

What you will learn

How joining input into a system command is dangerous, and how input checks prevent it.

Download lab (ZIP)
Info Safe

How the labs work

Every lab runs only in your browser using a pretend database or server written in JavaScript. Nothing is sent over the internet, so the labs are safe to run and cannot be used against real websites.
